# Agent Guidelines

To maintain complete workflow consistency and safety in this repository, follow these guidelines:

1. **Git Push Rule**: 
   - ALWAYS push changes ONLY to the `main` branch.
   - NEVER push to the `live` branch. The user will handle all operations on the `live` branch manually.
2. **Frameworks & Layouts**:
   - Keep all page modifications fully responsive and performant.
   - Maintain vanilla CSS design patterns in the website views.
