# App Development Portfolio

## Essential Files

### 📱 Main Portfolio
- **`portfolio_maximum.html`** - The complete portfolio webpage with all 16 apps and the new "My Role" field

### 🗄️ Data Source
- **`app_data_maximum.json`** - Complete app data including descriptions, screenshots, metadata, and role information

### 🔧 Generator Script
- **`generate_portfolio_with_roles.py`** - Python script to regenerate the portfolio with updated data

### 📦 Dependencies
- **`requirements.txt`** - Python packages needed to run the generator script

### 🖼️ Local App Assets
- **`melpot_local/`** - Melpot app icons and screenshots
- **`droob_local/`** - Droob app icons and screenshots  
- **`mo_mobyyou_local/`** - MO - mobyyou app icons and screenshots
- **`franck_muller_local/`** - Franck Muller Labs app icons and screenshots

### 🐍 Environment
- **`venv/`** - Python virtual environment with installed dependencies

## Features

✅ **16 Apps** with comprehensive data  
✅ **My Role Field** showing your contribution to each app  
✅ **Full Descriptions** with expand/collapse functionality  
✅ **Multiple Screenshots** per app (up to 10)  
✅ **Enhanced Metadata** including bundle ID, OS requirements, dates  
✅ **Professional UI** with search, filtering, and responsive design  
✅ **Local Assets** for apps with custom images  

## Usage

1. **View Portfolio**: Open `portfolio_maximum.html` in any web browser
2. **Regenerate**: Run `python generate_portfolio_with_roles.py` to update the portfolio
3. **Update Data**: Modify `app_data_maximum.json` to add/update app information
